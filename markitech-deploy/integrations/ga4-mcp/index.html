Google Analytics 4 integration

Get answers from GA4 without building explorations, and manage the property itself: key events, custom dimensions and metrics, data streams and Google Ads links. Admin changes are held for your approval.

What Markitech can do on Google Analytics 4

  • Run reports with any metrics, dimensions and date range Read
  • Realtime report Read
  • List properties and read property settings Read
  • List data streams, key events, custom dimensions and custom metrics Read
  • Read data retention, enhanced measurement and Google signals settings Read
  • List Google Ads links Read
  • Create, update or delete key events Approval required
  • Create, update or archive custom dimensions and custom metrics Approval required
  • Create, update or delete data streams Approval required
  • Create, update or delete Google Ads links Approval required

FAQ

Google Analytics 4 questions

Does Markitech change GA4 settings?

In the Markitech app it can create key events, custom dimensions and metrics, data streams and Google Ads links, and update property settings, each after your approval.

Can I use GA4 from Claude or ChatGPT?

Yes. Through Markitech's MCP server, your assistant can list properties and run reports. Changes are made in the Markitech app.
