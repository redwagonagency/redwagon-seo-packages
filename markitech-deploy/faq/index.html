Markitech / FAQ

Markitech questions, answered

How approval works, what Markitech connects to, how your accounts stay secure, and what it costs.

Using Markitech

What is Markitech?Markitech is an AI agent for marketing operations. In the Markitech app it works across Google Ads, Google Analytics 4, Google Tag Manager, Meta and 12 more platforms, and holds every change for your approval.Which AI assistants work with Markitech?Claude and other AI clients that support remote MCP servers with OAuth sign-in.Is Markitech affiliated with other marketing AI products?Markitech is an independent product, built from scratch, and is not affiliated with or reselling any other company’s service.What is an MCP server?An MCP server is a service that exposes tools an AI assistant can call through the Model Context Protocol, an open standard.How long does it take to set up Markitech?Connecting a platform takes under two minutes, because each one uses its own sign-in.

Plans and pricing

How much does Markitech cost?Markitech Pro is $79 a month for one user with 5,000 credits a month.What are Markitech credits?Credits are Markitech’s usage allowance. Each plan includes a monthly amount: 5,000 credits on Pro and 20,000 shared credits on Team.Can agencies use Markitech for client accounts?The Team plan is built for agencies and marketing teams: multiple user seats, unlimited connected accounts, a shared workspace, 20,000 shared credits a month and priority support.

Security and control

How does approval work in Markitech?Every write action, such as pausing a campaign, changing a budget or publishing a tag, is proposed in chat and held until you approve it.What can Markitech read without asking?Reporting and lookups, such as campaign lists, performance metrics, GA4 reports and Tag Manager container contents, run automatically, so you do not have to approve every question you ask.How does Markitech store my credentials?Markitech connects through each platform’s own authorization flow, so it never sees or stores your platform passwords.Is it safe to let AI manage ad accounts?It can be, if the controls are right. Use OAuth instead of passwords, connect only the accounts the AI needs, and make sure every change to a live account is held for a person to approve.

Platforms and tracking

Which platforms does Markitech support?Markitech supports 16 platforms today: Google Ads, Google Analytics 4, Google Tag Manager, Search Console, Merchant Center, Business Profile, Display & Video 360, BigQuery, Google Sheets, Docs and Slides, Meta Ads, Facebook Pages, Instagram, WhatsApp Business and WordPress.Can AI manage Google Ads campaigns?Yes, within limits you control. With Markitech, an AI can pull Google Ads performance, flag campaigns spending without converting, plan new campaigns, and pause or enable campaigns and change daily budgets.Can AI publish changes in Google Tag Manager?Markitech can create and edit tags, triggers and variables in a Tag Manager workspace and publish it, but only after showing you a readable change list and getting your approval.Does Markitech support server-side tagging?Markitech plans and configures server-side Google Tag Manager setups that send events to GA4, Google Ads enhanced conversions, the Meta Conversions API, the LinkedIn Conversions API and the TikTok Events API.Can Markitech fix GA4 tracking?Markitech reads your GA4 data and your Tag Manager container together to find the cause of a tracking problem, then fixes it through a Tag Manager change that you approve.Does Markitech work with the Meta Conversions API?Markitech sends Conversions API test events that Meta shows in Test Events without counting them, checks that your pixel and server events share an event_id, and builds server-side Conversions API tags in Tag Manager.Can Markitech make ad creatives?Yes, images. Markitech makes and edits ad images with Meta's image model in any aspect ratio, for feed, stories, reels and display, and writes the copy, hooks and video scripts to go with them.Does Markitech support Consent Mode v2?Markitech configures Google Consent Mode v2 in Tag Manager, including the ad_user_data and ad_personalization signals, region-specific defaults and updates from your consent banner, and checks that tags respect them.
